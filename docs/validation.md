# KTX 전용 구성 및 ktxctl 이름 변경 검증

검증일: 2026-09-11. SRT 제거, CLI·배포·Python 패키지명 변경을 확인했습니다.

## 동작

- 오프라인 호출 검증: 8개 메뉴의 직접 실행, 역·옵션 저장과 입력 취소,
  로그인 성공·실패·오류·취소, 일반실·특실·예약대기 조합 16개.
- 코레일 조회의 KTX 필터 유무, 승객 종류 5개, 예매·결제,
  잘못된 출발/도착역·승객수 입력, 미결제 취소와 결제 승차권 환불 확인.
- 위 CLI 검증에서는 keyring 및 코레일 API 호출을 테스트 대역으로 대체했습니다.
  실제 계정·카드 정보는 사용하지 않았고 실제 예매·결제는 수행하지 않았습니다.
- 기존 PR #54 토큰 생성 모듈을 새 패키지에서 불러오는 동작 확인.

## 설치 및 빌드

- `.venv`의 기존 `srtgo` 설치를 제거하고 로컬 `ktxctl`을 설치했습니다.
- 설치 메타데이터: 배포명 `ktxctl`, 명령 `ktxctl`, 진입점 `ktxctl.cli:ktxctl`.
- `.venv/bin/ktxctl --help`, 잘못된 옵션의 종료 코드 2 확인.
- `uv build`로 wheel·sdist 생성, SRT 클라이언트와 예전 `srtgo` 패키지가
  포함되지 않는지 검사. 추출한 wheel에서 CLI 도움말 실행 확인.
- `ruff check --select F821,F822,F823,F401`, `compileall`, `git diff --check` 통과.
- LSP는 기존 미설치 설정에 따라 생략. 기존 setuptools license 형식 경고는 유지.

코레일 API의 `srtCheckYn="N"`은 SRT 조회를 비활성화하는 프로토콜 필드이므로
유지했습니다. 원본 프로젝트 링크와 저작권 고지도 유지합니다.
